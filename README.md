# Proyecto GitFlow
## Realizado por: torrescusa05, ImAlex-png, elgancho06
---

En este proyecto se ve el funcionamiento claro de un control de ramas mediante la metodología de GitFlow, teniendo diferentes ramas.

- **main**: Rama de producción con la versión terminada.
- **develop**: Rama de desarrollo para probar nuevas funcionalidades.
- **feature**: Nuevas funcionalidades implementadas por el equipo.
- **release**: Versión del proyecto finalizada y preparada para ser añadida en main y develop respectivamente.
- **hotfix**: Versión de urgencia para arreglar vulnerabilidades o errores importantes.
